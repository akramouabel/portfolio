# Akram Ouabel — Mobile / Flutter Developer Portfolio

This is the repository for the personal freelance portfolio website of **Akram Ouabel**, Mobile Product Engineer and Flutter Developer.

## Project Purpose
The primary business goal of this website is to attract freelance clients by positioning Akram as a developer who can lead a mobile product from initial concept to a polished, high-performance cross-platform application.

---

## Tech Stack
The project is built on a clean, production-oriented architecture using:
- **Next.js** (App Router)
- **React** (v19)
- **TypeScript** (Strict)
- **Tailwind CSS** (v4.x)
- **ESLint**
- **Lucide React** (Icons)

## Getting Started

### Local Development
To launch the hot-reloading development server:
```bash
npm run dev
```

The application will be accessible at [http://localhost:3000](http://localhost:3000).

### Production Build
To check type safety, linting, and compile the production bundle:
```bash
npm run build
```

To run the built production server locally:
```bash
npm run start
```
